# 🤖 AI Productivity Assistant

An AI-powered productivity tool designed to help users automate everyday tasks and quickly extract insights from content.  
This full-stack application integrates AI to summarize, analyze, and generate responses efficiently.

---

## 💡 About This Project

This project was built to explore real-world AI applications and improve full-stack development skills, focusing on usability, performance, and intelligent automation.

---

## 🚀 Features

- 📧 Email Summarizer – Convert long emails into clear summaries  
- 🧠 Task Generator – Turn ideas into actionable steps  
- 💬 Auto Reply – Generate smart, context-aware responses  
- 📂 File Analyzer – Extract and analyze content from:
  - PDF
  - DOCX
  - PPTX
  - XLSX  

- ⚡ Fast and responsive UI  
- 🧠 AI-powered structured outputs  
- 🔄 Real-time processing via API  

---

## 🎯 Key Focus

- AI-driven productivity automation  
- Prompt engineering for accurate AI outputs  
- Clean and user-friendly UI/UX  
- Real-world use cases for professionals  

---

## 🛠️ Tech Stack

### Frontend
- HTML, CSS, JavaScript  
- Responsive UI design  
- Deployed on Vercel  

### Backend
- Python (FastAPI)  
- REST API  
- File processing (PDF, DOCX, PPTX, XLSX)  
- AI integration (content analysis & generation)
- Deployed backend services on Render with API handling and AI processing

---

## 🧠 How It Works

1. User inputs text or uploads a file  
2. Frontend sends request to backend API  
3. Backend processes input and prepares structured prompt  
4. AI analyzes content and generates response  
5. Results are returned and displayed in a structured format  

---

## ⚙️ Challenges & Learning

- Designed effective **prompt engineering** strategies to ensure accurate and structured AI outputs  
- Handled multiple file formats and ensured consistent text extraction  
- Debugged full-stack issues across frontend, backend, and AI responses  
- Improved system reliability and response quality through iterative testing
